## Project Description

The Portfolio Template Generator is a web application designed to help users create professional personal portfolios without building them from scratch. Users can enter their personal information, educational background, skills, projects, work experience, and social media links. They can choose from three different templates and preview their portfolio before saving or managing it.

The application is designed with a responsive layout so users can access the website using computers, tablets, and mobile devices.

## Features

- Create a personal portfolio.
- Enter personal information and contact details.
- Upload a profile picture.
- Add an About Me section.
- Add educational background.
- List skills and projects.
- Include work experience.
- Add social media and website links.
- Choose from three different portfolio templates:
  - **Simple:** Clean and professional design.
  - **Modern:** Contemporary layout with organized sections.
  - **Creative:** Colorful and distinctive design.
- Preview portfolio information.
- Save and manage portfolios.
- View, edit, and delete saved portfolios.
- Responsive website design.

## How to Run the Project Locally

### Prerequisites

Install Node.js and npm on your computer.

### Installation Steps

1. Clone the GitHub repository:

   ```bash
   git clone https://github.com/pahayahayhenry72-jpg/portfoliogenerator.git
   ```

2. Open the project folder:

   ```bash
   cd portfoliogenerator
   ```

3. Install the required packages:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm.cmd run dev
   ```

5. Open the local URL shown in your terminal, usually:

   ```text
   http://localhost:5173/
   ```

## Database Configuration

If Supabase integration is enabled, configure the following environment variables in your local `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_publishable_or_anon_key
```

Use the public client key intended for browser applications. Never put your Supabase service-role key in frontend code.

Make sure the Supabase project and required database table are configured before using database features.

If the application uses browser Local Storage instead, saved data is stored in the user's browser and does not automatically synchronize across devices.
